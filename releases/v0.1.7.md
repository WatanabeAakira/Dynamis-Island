## Notifikasi aplikasi Windows

- Toast dari aplikasi Windows yang teksnya tersedia lewat UI Automation bisa dimasukkan ke riwayat tab Notifikasi.
- Notifikasi menyimpan nama aplikasi, judul, isi pesan, dan waktu diterima. Riwayat tetap memakai penyimpanan lokal aplikasi.
- Pengaturan baru ada di **Pengaturan → Notifikasi**. Penangkapan bisa diaktifkan atau dimatikan dari window Settings, dan status helper serta jumlah riwayat ikut tersambung.
- Fitur bekerja saat Dynamis Island berjalan. Hasil tangkapan bergantung pada informasi yang diekspos Windows dan aplikasi sumber.

## Catatan

- Banner bawaan Windows tetap dapat muncul. Windows tidak menyediakan cara aman bagi aplikasi unpackaged ini untuk menahan banner aplikasi lain sambil menggantinya dengan tampilan island.
- Notifikasi yang tidak menampilkan teks melalui UI Automation tidak bisa disalin ke island.
- Helper C# dibangun self-contained dan ikut dibundel di installer; pengguna tidak perlu memasang .NET terpisah.
