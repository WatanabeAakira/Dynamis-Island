# Dynamis Island v0.4.2

## Native multi-monitor support

- Choose Primary Monitor Only, All Monitors, or Custom under Settings → Display → Multi-Monitor.
- View connected display information and their arrangement, and configure visibility for each display in Custom mode.
- Run independently managed Island windows on enabled displays while sharing application data and background services.
- Detect display changes, ask before showing the Island on a newly connected display, and preserve monitor preferences across restarts when a stable monitor ID is available.
- Synchronize alarm takeover across displays and return to each display's saved visibility after the alarm is dismissed or snoozed.

## Compatibility and verification

- Existing settings are retained; display mode defaults to Primary Monitor Only.
- Automated tests and the Windows x64 installer build passed before release.
- Physical multi-monitor behavior was manually tested by the maintainer before publishing this update.
