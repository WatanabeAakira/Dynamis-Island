# Dynamis Island v0.4.0

## New features

- Added Clipboard Manager with local history for text, images, links, and files, plus search, filters, previews, pinning, cleanup, exclusions, and pause/resume capture controls.
- Added Quick Notes with local persistence, autosave, search, pinning, and clipboard-to-note actions.
- Added Quick Settings for supported Windows connectivity, audio, display, power, and appearance controls, with unsupported controls opening the matching Windows Settings page.
- Added System Monitor for CPU, memory, storage occupancy, network traffic, process usage, and configurable performance alerts.
- Added optional handoff of selected clipboard, note, and system data to existing Translate Anything and AI Assistant features.

## Improvements

- Implemented new feature services in the shared C# helper and connected them to the Electron UI.
- Kept feature layouts within the centralized Expanded Mode sizing system.
- Added dedicated settings pages for Clipboard Manager, Quick Notes, Quick Settings, and System Monitor.

## Compatibility and limitations

- Windows x64. Clipboard history and notes stay on the device.
- GPU utilization, VRAM utilization, and CPU/GPU temperature depend on a supported hardware telemetry provider and may be unavailable.
- Network traffic and process CPU values are sampled locally by the C# helper.

## Verification

- Automated tests and Windows helper/build verification are recorded with the batch completion report.
