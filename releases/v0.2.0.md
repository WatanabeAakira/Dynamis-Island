# Dynamis Island v0.2.0 - Copy Text From Anything

## Overview
Dynamis Island now includes a native offline OCR workflow for extracting text from any visible screen area.

## New Features
- Native Windows screen-region selection with click-and-drag capture.
- ESC cancellation and multi-monitor virtual-screen capture support.
- Offline OCR using Windows `Windows.Media.Ocr` APIs.
- Global `Ctrl + Alt + T` shortcut.
- Automatic copying of recognized text to the Windows clipboard.
- Copy Text tab with status and processing indication.
- OCR language selection based on installed Windows language packs.
- Enable/disable control for the global shortcut.

## Technical Improvements
- OCR and global hotkey handling run in the existing C# IslandHelper process.
- Electron communicates with the native helper through the existing JSON-lines protocol.
- Screen capture, OCR, and clipboard operations remain local and do not upload content to external services.

## Privacy
Captured images and extracted text are processed locally only. No screenshot or OCR text is stored permanently or sent to a cloud service.

## Compatibility
- Windows 10 19041 or newer is recommended.
- An appropriate Windows OCR language pack must be installed for non-automatic recognition.
- The selected region must be visible on a connected monitor.
