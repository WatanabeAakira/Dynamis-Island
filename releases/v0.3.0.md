# Dynamis Island v0.3.0 - Translate Anything

## Overview

Translate Anything adds direct text, image, and screen-region translation to Dynamis Island, with original and translated text shown side by side.

## New Features

- Type or paste text and translate it automatically or on demand.
- Import images and extract text with Windows OCR.
- Select a screen region and translate its OCR text, including with the global `Ctrl + Alt + Y` shortcut.
- Detect the source language automatically or choose languages manually.
- Copy the translated result and view the original alongside it.
- Reuse the existing local OCR and screen-selection infrastructure.
- Select Automatic provider routing, prefer Groq, or use MyMemory without an API key.
- Automatic routing prioritizes Groq when a key is configured and falls back to MyMemory otherwise.

## Technical Improvements

- Added a modular translation-provider adapter for MyMemory alongside the existing Groq adapter.
- Translation requests run through Electron's main process; provider keys stay out of renderer code.
- Long fallback requests are split at safe UTF-8 boundaries to meet MyMemory's request limit.
- The hover tab bar adapts to available display width and supports horizontal scrolling as more features are added.

## Privacy

Screen capture and OCR run locally through Windows OCR. Dynamis Island sends only text entered by the user or extracted by OCR to the selected online translation provider. MyMemory works without setup and its anonymous service has a daily usage limit.

## Compatibility

- Windows x64 installer; Windows OCR language packs are needed for the OCR languages installed on the device.
- Translation requires an internet connection.
- Groq translation requires a Groq API key. MyMemory can be used without a key and is subject to its anonymous daily quota.
