# Dynamis Island v0.4.4

## Network Monitor & Battery and Power Manager

- Tambahkan tab Network Monitor dengan status koneksi, trafik real-time, statistik sesi, dan pemakaian bulanan.
- Pemakaian bulanan mencakup Wi-Fi dan Ethernet, disimpan lokal, dan dimulai ulang otomatis tiap bulan.
- Tambahkan Battery & Power Manager untuk status baterai, mode daya Windows, konsumsi daya yang tersedia, dan rekomendasi.
- Ringkas tampilan Compact semua fitur agar lebih dekat ke ukuran Media Player, termasuk mini lyrics yang tetap bisa melebar mengikuti lirik.
- Tambahkan preset animasi lirik Subtle, Smooth, Kinetic, Elastic, Morph, Wave, Cinematic, dan Custom.

## Catatan update

GitHub Actions akan membangun installer Windows dan metadata auto-update untuk rilis ini. Installer tidak dibangun secara lokal.
