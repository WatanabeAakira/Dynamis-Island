# Dynamis Island v0.4.3

Pembaruan ini memoles tampilan kalender dan kartu Timer, Focus, Alarm, serta menambahkan animasi saat artwork lagu berganti.

## Tampilan

- Kalender mendapat latar berlapis, pencahayaan dan refleksi glass yang lebih terasa, serta kartu tanggal yang lebih berdimensi.
- Kartu Timer, Focus, dan Alarm kini lebih pendek, memakai aksen warna terpisah, tagline, dan bar status.
- Animasi cover art Media dibuat lebih halus dan mengikuti pengaturan Reduced Motion.
- Performa tampilan kalender dioptimalkan dengan membatasi efek visual terberat ke tanggal aktif dan sekitarnya.

## Catatan update

Versi installer Windows dan metadata auto-update akan dibuat oleh GitHub Actions untuk rilis ini. Aplikasi versi sebelumnya akan mengunduh update setelah rilis dipublikasikan.
