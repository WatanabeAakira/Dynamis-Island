# Dynamis Island v0.3.1

## Improvements

- Set Expanded Mode to a 260 CSS px default with centralized 200–360 px sizing limits and per-feature preferred heights.
- Reflowed Media Player, Audio Control, Clock, Copy Text, Calendar, and other feature tabs to use screen space more efficiently.
- Reduced Hover Mode to a 46 px strip, tightened its icon layout, and added a More grid that keeps every feature accessible.
- Added a shared minimal floating scrollbar style with neutral gray colors, a transparent track, and a stable 4–5 px thumb.
- Applied consistent scrollbars to lists, panels, and horizontal scrollers, with a 1 second return to idle after scrolling.
- Reserved scrollbar gutters to prevent content shifts and respected Windows Reduced Motion preferences.

## Testing

- Automated test suite passed: 19/19.
- JavaScript syntax checks passed.
- Windows helper and NSIS installer build completed successfully.

## Compatibility

- Windows x64 installer.
- Existing application version remains compatible with the GitHub automatic update workflow.
